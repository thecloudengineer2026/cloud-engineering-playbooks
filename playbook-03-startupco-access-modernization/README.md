# Cloud Engineering Playbooks

This repository contains cloud engineering case studies documenting my journey from Business Analyst to Business Solutions Architect.

Each playbook addresses a real-world business problem and documents the architecture, implementation, validation, security decisions, tradeoffs, and lessons learned.

## Current Case Studies

### [Playbook 02 - Secure AWS Foundation](playbook-02-secure-aws-foundation/)

A cost-conscious AWS security foundation using IAM, MFA, CloudTrail, Amazon S3, CloudWatch Logs, metric filters, alarms, and Amazon SNS.

### [Playbook 03 - StartupCo Secure Access Modernization](playbook-03-startupco-access-modernization/)

A role-based AWS identity and access-management solution replacing shared root credentials with individual identities, scoped permissions, MFA enforcement, credential auditing, and positive and negative authorization testing.

## Portfolio Focus
